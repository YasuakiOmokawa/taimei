# Product Overview

Taimei（泰明）は「心安らかなソリューション」をコンセプトとしたWebアプリケーション。

## Core Capabilities

- **ダッシュボード機能**: 請求書・顧客データの可視化と管理
- **顧客管理**: 顧客情報のCRUD操作
- **請求書管理**: 請求書の作成・編集・一覧表示
- **認証システム**: Better Auth による GitHub OAuth / Magic Link 対応

## Target Use Cases

- 小規模ビジネス向けの請求書・顧客管理
- シンプルで直感的な業務データ管理

## Value Proposition

- **型安全性**: Effect-TS による堅牢なエラーハンドリング
- **モダンスタック**: Next.js App Router + React 19 による最新のDX
- **テスタビリティ**: サービスパターンによる高いテスト容易性
