# 認証コールバックのパターン設計

認証方式   | 認証方法 | すでに同名のemailが登録されていた場合                    | アカウント連携                                     |
==========+==========+=======================================================+===================================================
magiclink | 新規登録  | 登録失敗。ログインしてとメッセージを出す                 | -                                                 |
----------+----------+-------------------------------------------------------+---------------------------------------------------+
magiclink | ログイン  | ログイン成功。成功メッセージを出す                       | -                                                 |
----------+----------+-------------------------------------------------------+---------------------------------------------------+
github    | 新規登録  | アカウント連携を確認                                    | されていれば登録失敗。ログイン後にアカウント連携してとメッセージを出す   |
----------+----------+-------------------------------------------------------+----------------------------------------------------+
github    | ログイン  | アカウント連携を確認                                    | されていればログイン成功。成功メッセージを出す         |
----------+----------+-------------------------------------------------------+----------------------------------------------------+
